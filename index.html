THE BASICS 🌸

So, what exactly is SHAP?

SHAP stands for SHapley Additive exPlanations. It uses ideas from cooperative game theory to explain how features contribute to a model's prediction.

🔎

Feature impact

See which input features push a prediction higher or lower relative to a baseline.

🧩

Understand a result

Break an individual prediction into contributions from the features used by a model.

💜

Build understanding

Use explanations to investigate model behaviour. SHAP supports interpretation, but does not prove that a model is fair or correct.

🌱 The key idea

Each feature receives a SHAP value. Positive values generally move the prediction above its baseline, while negative values move it below the baseline. The exact meaning depends on the model output being explained.

QUICK RECAP 💌

Why does SHAP matter?

Machine learning can make useful predictions, but understanding the reasons behind them is also important. SHAP offers a structured way to examine feature contributions for individual predictions and across datasets.

🎯

Local explanations

Investigate the feature contributions for one specific prediction.

🌍

Global insights

Summarise feature importance across many predictions, for example using mean absolute SHAP values.

📖

Keep learning

Explore SHAP documentation and practise with a trained model before interpreting real-world results.
